# Bilibili 歌单自动播放器

导入歌单 → 自动在 B 站搜索每首歌 → 在浏览器里播放 → 播完自动搜下一首并播放。

## 运行

```bash
pip install -r requirements.txt
python main.py
```

依赖：`requests`、`websocket-client`（本机已装）。界面用 tkinter（Python 自带）。
播放依赖系统里真实的 **Edge 或 Chrome**（内嵌浏览器控件普遍缺 H.264/AAC 解码，会没声音，所以这里用 CDP 驱动真实浏览器）。

## 使用步骤

1. **导入歌单**：点「导入歌单」，支持
   - `.txt`（每行 `歌名 - 歌手`，可直接用仓库里的 `sample_playlist.txt`）
   - `.m3u / .m3u8`、`.csv`（歌名,歌手）、`.json`
   也可以点「添加」手动输入，或「保存」导出。
2. **播放**：选中某首双击，或点底部「▶ 播放」。程序会自动
   - 用 `歌名 + 歌手` 调 B 站搜索接口（含 WBI 签名与风控 Cookie）拿到候选视频
   - **默认直接播放搜索结果列表的第一条**（匹配方式可在设置里改）
   - **直接打开视频原页面** `https://www.bilibili.com/video/{BV号}` 播放（不使用内嵌播放器），
     清晰度切换、弹幕、评论、会员/登录限制全部与正常看视频一致
   - 候选列表显示在右侧，**双击任意一条可立即换视频**
3. **自动连播**：默认开启「自动连播下一首」，一首播完 2 秒后自动播放下一首；出错/无结果 3 秒后跳过。
4. **抽选模式**（歌单工具栏「🎲 抽选 N 首」）：
   - **抽选个数可在「⚙ 设置 → 播放 → 抽选个数」里改**（1–99，默认 2），按钮文字会跟着变
   - 歌单首数不够会弹窗提示（例如设 5 首但只有 3 首）
   - **抽选动画**：程序目录里有 `video.mp4` 时，会**全屏独占**播放它，**播完一遍才关闭**并出结果；
     期间点一下或按 `Esc` 可立即跳过。视频短于 1.2 秒会循环到 1.2 秒，长于 8 秒则到 8 秒兜底结束。
     没有 `video.mp4`（或没装 opencv/pillow）时自动退回原来的列表闪动动画。
     想换动画直接替换 `video.mp4` 即可（当前是默认占位动画）
   - 点一下会先跑**抽取动画**：列表快速随机闪动并逐渐减速，约 3 秒后定格在抽中的两首
   - 抽中的曲目标成浅粉底，并列入右侧下方的「抽选结果」区：
     `▶` 播放中 / `✓` 已播 / `·` 待播 / `✗` 已从歌单移除
   - **抽过的歌不再参与后续抽选**（设置里可关）：歌单里会标成浅粉，顶栏显示「未抽过 N 首」；
     没得抽时提示「重置抽选记录」。每首歌按**唯一编号**区分，歌单里有重复的同一首歌也互不影响
   - **记忆未抽歌单**（设置 → 播放，默认开启）：已抽记录会写进 `settings.json`，
     下次启动自动载入上次歌单时**只载入没抽过的歌**（状态栏会提示跳过几首）；
     全部抽完会提示「重置抽选记录」。导入新歌单会自动清掉旧的已抽记录
   - 可选「播完后自动从歌单移除」（设置 → 播放）：每首播完就把它从歌单删掉，
     **删除前自动把完整歌单另存为程序目录下的 `歌单备份.txt`**，随时可恢复
   - 「重置抽选记录」按钮：清掉抽过标记，所有歌重新参与抽选
   - 定格后**只出结果、不自动播放**（不打断当前正在放的歌），等你选择
   - 抽中后会**后台预先搜索**这几首，并把第一首的搜索结果显示在上方「搜索结果」区，
     所以抽完就能看到候选视频；选中时直接用缓存，不用再等搜索
   - 选择方式：双击「抽选结果」里某一首（或选中后按回车）、点「▶ 播放抽选结果」按顺序连播，
     也可以直接双击上方「搜索结果」里的某一条来播放它；
     选择后才建立连播队列，播完提示「抽选播放完毕」
   - 抽选结果页可**双击某一首**直接从它开始播，或用「▶ 播放抽选结果」从头再播一遍
   - **爆率机制**（设置 → 播放 → 抽选爆率）：默认仍是完全均匀随机。开启「按歌单标注的爆率（权重）抽选」后，
     可在歌单里用 `歌名 - 歌手 @3` 给某首歌标权重（数字越大越容易被抽到，默认 1，保存歌单时会写回）；
     开启「后台保底」后，程序按抽选历史在后台自动提高**越久没被抽到**的歌的爆率（保底强度可调，约 3 天封顶），
     让每首歌都有机会被抽到。两者可叠加。
5. **队列播放**（播放控制条「▶ 队列播放」/ 抽选结果页同名按钮）：
   - 从当前选中（或第 1 首）开始，按歌单顺序连续播放到结尾，不再依赖「自动连播」开关
   - 底部实时显示进度：`队列：2/4`、`抽选：1/2`
   - 「下一首」在队列进行中走队列；点「停止」结束队列（抽选结果保留）
6. **强制保持播放页面在前台**（只要没点「停止」）：
   - 标签页被叉掉：数秒内自动重开标签页（浏览器还活着就不重启浏览器）并接着播
   - 浏览器窗口/进程被关掉：自动重新拉起整个浏览器，从关闭前的进度续播
   - 页面被逛走（点了推荐视频、回到首页等）：检测到 URL 不是当前视频就强制导航回来
   - 切走标签页 / 窗口最小化：自动 `bringToFront` 抢回焦点（10 秒冷却，避免一直弹窗）
   - 连续失败 5 次后放弃，避免死循环；点「停止」后不再拉起
6. **定时关闭**：点控制条「⏱ 定时」弹出设置对话框 —— 可选「倒计时（分钟）」输入或快捷 15/30/60/90/120，
   或「指定时间（HH:MM）」选具体时刻（如 23:30，已过则顺延到明天）；可设「到点后播完当前这首再停」
   与「停止播放 / 退出程序」；按钮与状态栏实时显示剩余 `⏳ 12:34`（指定时间模式显示目标时刻）。
   点「停止」会取消定时。
   默认「播完当前这首再停」，不会把歌拦腰截断；点「■ 停止」会取消定时。
   默认值在「⚙ 设置 → 播放」里改（分钟数 / 停止播放·退出程序 / 是否播完再停）。
7. 底部可「上一首 / 暂停 / 下一首 / 停止 / ⤢ 拉回前台 / ⏱ 定时」，并显示 `已播时间 / 总时长` 与进度条。
   「拉回前台」可手动强制把页面切回来并导航回当前视频。
   按暂停后按钮变「▶ 继续」，**暂停状态会一直保持**：自动播放兜底和强制拉回都不会把它重新播起来，
   页面被重载后会跳回原进度并保持暂停。切下一首时自动恢复播放状态。

## 打包成 exe

```bat
pip install pyinstaller
build.bat
```

产物在 `dist\BilibiliMusicPlayer\`（`BilibiliMusicPlayer.exe` + `_internal`）。
想打成单个文件，把 `build.bat` 里的 `--onedir` 换成 `--onefile`（启动会慢一些，因为每次要解压）。

打包后与源码运行的差别：
- `settings.json` 生成在 **exe 所在目录**（配置可持久化），不带进程序内部。
- `video.mp4` 已随程序打包；想换动画，把新的 `video.mp4` 放到 exe 同目录即可覆盖，
  或在「⚙ 设置 → 播放 → 动画文件」里指定任意路径。

## 界面

- 浅色玻璃界面：半透明 + 圆角，标题栏也跟随浅色。
  **默认走「浅色实底」（背景必定是白的）**；想要真·毛玻璃，在「⚙ 设置 → 外观」里
  取消「背景用浅色实底」即可切到亚克力（此时用自定义浅色 tint，系统深色模式也不会把界面带暗）。
- 顶栏（标题那一栏）可以直接拖动窗口 —— 开启毛玻璃后透明区域不接收鼠标，特地把顶栏做成实底并加了拖拽。
- **分辨率 / 缩放自适应**：
  - 启动时开启 Per-Monitor DPI 感知，并按屏幕 DPI 设置 Tk 缩放，高分屏不糊、字不会过小
  - 窗口初始尺寸按屏幕**工作区**（排除任务栏）计算并居中，最大 1180×760、最小 880×560，
    小屏会自动收缩，最小尺寸也随屏幕下调
  - 记住上次窗口大小与位置；换显示器/改分辨率后如果旧位置跑到屏幕外，会自动改回居中默认尺寸
  - 设置对话框同样按工作区收缩居中，并允许拉大
- 主窗口布局：左侧歌单，右侧**上下两块独立区域** —— 上面「搜索结果」，下面「抽选结果」，
  各自带按钮、同时可见，不再用分页切换；**两块之间的分隔条可以拖动**，随时调整各自高度，
  拖出来的比例会记在设置里（搜索区最小 140px、抽选区最小 110px）。
  **其余配置都收进右上角「⚙ 设置」**。

## 设置说明（⚙ 设置）

**播放**
| 设置项 | 说明 |
| --- | --- |
| 自动连播 | 播完是否自动跳下一首 |
| 匹配方式 | **默认「搜索结果第一首」**，直接播放搜索结果第一条；可切到「智能最佳匹配」，按标题/歌手命中、时长、播放量打分挑选 |
| 抽选个数 | 点「🎲 抽选」时抽几首，1–99，默认 2；按钮文字随之变化，歌单不够会提示 |
| 抽选爆率（权重 + 保底） | 默认均匀随机；可开启「按权重抽选」（歌单用 `歌名 - 歌手 @3` 标权重）和/或「后台保底」（越久没抽到的歌爆率越高，强度可调） |
| 播完后自动从歌单移除 | 播完就把这首从**当前列表**去掉（不改你的歌单文件，删除前备份到 `歌单备份.txt`）。与下面一项**二选一** |
| 记忆未抽歌单 | **默认开启**：列表保持完整，但下次启动不再载入（也不会再抽到）已抽过的歌。与上面一项**二选一** |
| 抽选时全屏播放视频动画 | **默认开启**：抽选时全屏独占播放动画，点一下或 `Esc` 可跳过；关掉则用列表闪动动画 |
| 动画文件 | 留空 = 用程序目录里的 `video.mp4`；也可指定任意视频文件（mp4/webm/mov/avi/mkv）。下方会实时显示当前生效的是哪个文件 |
| 时长范围 | 默认 60–900 秒；仅在「智能最佳匹配」模式下参与打分过滤 |

**浏览器**
| 设置项 | 说明 |
| --- | --- |
| 浏览器 | 自动探测 Edge/Chrome，找不到时手动选 `msedge.exe` / `chrome.exe` |
| 调试端口 | 默认 9222，冲突时可改（下次启动浏览器生效） |
| Cookie（可选） | 填 `SESSDATA=xxx; bili_jct=xxx` 可降低被风控概率；获取方式：浏览器登录 B 站 → F12 → 应用/存储 → Cookie |
| 登录 | 在程序专用的浏览器窗口里登录 B 站，登录态保存在独立 profile，可解锁高码率与会员/地区限制视频 |

**外观**
| 设置项 | 说明 |
| --- | --- |
| 亚克力 / 毛玻璃 | 开关半透明窗口材质 |
| 背景用浅色实底 | **默认开启**：浅色底 + 整体半透明，背景必定是白的，也不受鼠标穿透影响。取消后改用亚克力毛玻璃 |
| 背景白度 | 120–255，控制毛玻璃底色的白度，越接近 255 越白（仅亚克力模式生效；默认 235） |
| 不透明度 | 0.70–1.00，默认 0.96；内容看不清时调高 |

> 程序使用独立的用户数据目录（`%TEMP%\bili_player_profile`），不会影响你日常用的浏览器。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `main.py` | tkinter 图形界面、播放调度、线程与 UI 队列 |
| `ui_theme.py` | 毛玻璃/亚克力窗口效果（DWM）与 ttk 主题配色 |
| `video_overlay.py` | 抽选时的全屏视频动画（opencv 读帧 → Tk 渲染），缺失依赖自动降级 |
| `video.mp4` | 抽选动画素材，可直接替换 |
| `app.ico` | 程序图标（打包用） |
| `build.bat` | 一键打包脚本（PyInstaller，onedir + 无控制台） |
| `dist\BilibiliMusicPlayer\` | 打包产物，双击 exe 即可运行 |
| `settings_dialog.py` | 「⚙ 设置」分页对话框（播放 / 浏览器 / 外观） |
| `bilibili.py` | B 站搜索接口（WBI 签名、风控 Cookie）与「最佳匹配」打分 |
| `player.py` | CDP 客户端：启动/驱动 Edge 打开视频原页面、读取 video 播放状态、播完回调 |
| `playlist.py` | 歌单模型与 txt/m3u/csv/json 导入导出 |
| `settings.json` | 运行时自动生成的配置（浏览器路径、Cookie、时长范围等） |

## 常见问题

- **搜索返回 0 条 / 提示风控**：在设置里填入 B 站 Cookie，或点「打开登录窗口」登录后重试。
- **没有声音/画面**：确认设置里的浏览器路径正确；程序会把自动播放兜底打开，若仍被拦截点一下「暂停」再点一次即可继续。
- **某首歌匹配不准**：右侧结果列表里双击更合适的视频，或点「重新搜索」换个关键词。
